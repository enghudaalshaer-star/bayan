# اختبارات بيان

تشغّل الموقع ولوحة التحكم في متصفح محاكى (jsdom) وتمرّ على كل الصفحات وأهم العمليات، وتفشل إن ظهر أي خطأ JavaScript أو نص `undefined` / `NaN` في الصفحة.

```
cd tests
npm install
npm test
```

- `run.js` يشغّل الموقع في الوضع التجريبي ويحفظ البيانات التجريبية في `.tmp/seed.json`.
- `sweep.js` كل صفحات الموقع (زائر وطالب) ولوحة التحكم في الوضع التجريبي.
- `flows.js` عمليات: قبول طلب، القيد، الطلاب، الشهادات، صفحة الفصل، امتحان رسمي كامل، اختبار ذاتي حتى إصدار الشهادة.
- `livesweep.js` الصفحات نفسها بمسار Firebase (Remote + الذاكرة المؤقتة + العدّ على السيرفر) فوق Firebase محاكى في `fakefb.js`، ويطبع عدد القراءات لكل صفحة. `CATALOG=1` مع وجود فهرس الدورات.

لا تختبر قواعد Firestore ولا الدوال على سيرفر حقيقي.
